# VIRASAT — Cinematic Heritage Collectibles

A responsive, cinematic Indian heritage storefront concept built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — website structure
- `styles.css` — responsive design and visual styling
- `app.js` — collection filtering, search, product details, wishlist and demo cart
- `products.json` — editable sample catalogue data
- `assets/virasat-hero.jpg` — cinematic hero artwork

## Preview locally
Open the folder in VS Code and use the Live Server extension, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Upload to GitHub
1. Open your `virasat_site-1` repository.
2. Choose **Add file → Upload files**.
3. Extract this ZIP on your computer.
4. Upload the contents of the `virasat-github-site` folder (not the outer folder itself).
5. Commit the upload.
6. In GitHub, open **Settings → Pages**.
7. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.

If GitHub Pages is already enabled, wait a few minutes for deployment.

## Important before accepting real orders
This is a front-end demo. Cart and wishlist use browser local storage. Checkout is demonstrational only; no real payment is taken and no order is sent to a server. Connect a secure backend and a payment provider such as Razorpay before taking live orders. Replace sample catalogue entries, prices, product descriptions and imagery with your actual products.
